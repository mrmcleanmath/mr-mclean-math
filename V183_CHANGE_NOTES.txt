Mr. McLean Math v183

Pi Memory Challenge frame-pacing repair
- The full-screen moving Tron floor now uses compositor-friendly transform motion instead of repainting its large gradient background every frame.
- Correct digit entry now appends only the new visible digit instead of rebuilding the entire digit history.
- The hidden full-digits view is populated only when opened, rather than rebuilt after every entry.
- The lives display is no longer rebuilt when the number of lives has not changed.
- Cursor scrolling is coalesced into one frame without repeated geometry measurements.
- Pi fill bounds are measured once and reused, and the routine digit landing pulse no longer forces a synchronous page layout.
- The adaptive performance fallback now monitors only while a run is active, and its reduced-effects modes cannot be overridden by later desktop animation rules.
- Game rules, scoring, modes, audio, controls, and the established visual design are unchanged.
